# Changelog

## 0.3.3 alpha — 16 October 2026

- First downloadable macOS release, with a Universal app for Apple silicon and
  Intel Macs running macOS 26 or later.
- DMG and ZIP packages include the Android runtime tools and their license notices.
- Download and installation instructions are available from the landing page.
- The control dock builds with the macOS 26 SDK.

This alpha uses local ad-hoc code signatures. It is not Developer ID signed or
Apple notarized, and macOS may require explicit approval on first launch.

## 0.3.2 — 16 October 2026

Initial public source snapshot: native wireless Android mirroring, QR/code
pairing, text clipboard sharing, safe file uploads, connection recovery and
adaptive video quality. See the architecture and historical verification notes
under `docs/` for implementation details and validation scope.
